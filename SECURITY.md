# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's
[private vulnerability reporting](https://github.com/kerembolek/HelpdeskOps/security/advisories/new) instead.

Include the affected page or endpoint, the role you were signed in with, and the steps to reproduce.

Reports get a first answer within five working days. Fixes ship in the next release, and [CHANGELOG.md](CHANGELOG.md) lists them.

## Supported versions

Only the latest release receives security fixes.
